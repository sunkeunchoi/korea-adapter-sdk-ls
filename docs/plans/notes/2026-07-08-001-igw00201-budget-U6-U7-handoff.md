# IGW00201 budget — operator runbook (U6 + U7)

Attended, **paper-only** sessions that issue live gateway calls. U1–U5 (offline code)
are landed and gate-green; U6 and U7 are the operator's job and cannot be automated.
Run U6 first (measure the budget), then U7 (prove the ingest).

---

## 0. One-time prep

```bash
export LS_TRADING_ENV=paper
cargo build --bins -p nautilus-ls        # debug — release builds die mid-compile here
```

### The spare credential lane (`.env.<spare>`)

U6 stage 0 needs a **second** LS paper app key, distinct from the domestic lane's, so
it can ask "is the IGW00201 budget per-key or shared?" — one call on the spare key
while the domestic key is exhausted.

Create a gitignored credentials file at the repo root, same shape as `.env.domestic`
(run `cat .env.domestic` to see its exact keys), but with the **spare** app's values:

```bash
cat > .env.spare <<'EOF'
LS_TRADING_ENV=paper
LS_PAPER_APIKEY=PS...            # the SPARE app's key (a 2nd registration in the LS portal)
LS_PAPER_SECRET=...              # the SPARE app's secret
LS_PAPER_ACCOUNT=555...          # the SPARE app's paper account no
EOF
chmod 600 .env.spare
```

> **Only one paper credential?** Stage 0's scope test isn't possible. Treat the budget
> as shared (the plan's AE2 branch): skip stage 0, and schedule stages 1–3 onto a **cold
> window** (a day/time with no recent domestic or probe spend). Say so in the promoted
> `provenance`.

### Two rules that decide the whole session

1. **Stage 0 is about *keys*, not days:** it must call the **spare** key while the
   **domestic** key is verifiably budget-exhausted. Probing the domestic key with
   itself answers nothing.
2. **Stages 1 → 2 → 3 must run back-to-back in one sitting.** Stage 2 measures how long
   the bucket takes to refill *after stage 1 drains it*. Split them across days and the
   budget refills overnight — stage 2 measures nothing.

## U6 — measure the budget, then promote the numbers

### Step 1 — exhaust the domestic key

Run a normal domestic ingest/read until it trips `IGW00201` (or run right after one that
just did). That exhausted state is the context stage 0 needs.

### Step 2 — probe

Recommended: one command, on the spare lane. Stage 0 checks scope; if per-credential the
same run measures cold-budget → refill → cross-class. **The binary auto-stops after stage
0 if it detects a shared (broader-than-credential) budget** — it records the note and
refuses to keep burning the shared budget.

```bash
LS_PROBE_LANE_FILE=.env.spare LS_PROBE_STAGES=0,1,2,3 LS_PROBE_CEILING=40 \
  ./target/debug/budget-probe
```

- **Env var is `LS_PROBE_LANE_FILE`** (not `LS_CAPTURE_LANE_FILE` — that's for
  `capture-universe`).
- Stage 2 sleeps at widening intervals (default `30,60,120,240`s ≈ up to ~7 min of
  waiting) — expected.
- Prefer to eyeball scope before committing calls? Split only at stage 0:
  ```bash
  LS_PROBE_LANE_FILE=.env.spare LS_PROBE_STAGES=0     ./target/debug/budget-probe   # read scope
  LS_PROBE_LANE_FILE=.env.spare LS_PROBE_STAGES=1,2,3 ./target/debug/budget-probe   # then measure
  ```

### Step 3 — read the report + branch

Report lands at `probes/budget-model-report.json` (override `LS_PROBE_OUT`).

| `stage0_scope.scope`     | Meaning              | Do                                                                 |
|--------------------------|----------------------|--------------------------------------------------------------------|
| `per_credential` (AE1)   | Budget is per-key    | Continue stages 1–3 on the spare key **this session** (as above).  |
| `broader_than_credential` (AE2) | Budget is shared | **Stop same-day.** Re-run stages 1–3 on a cold window (a fresh day). |

### Step 4 — promote the measured numbers

Edit `adapters/nautilus/lab/config/gateway-budget.json` (committed, reviewed), replacing
the provisional values:

| Field          | From                                   | Note                                          |
|----------------|----------------------------------------|-----------------------------------------------|
| `budget_calls` | stage 1 `calls_served`                 | **This turns plan-ahead ON.** null = off.     |
| `refill_secs`  | stage 2 `first_success_secs`           | The measured backoff/refill window.           |
| `window_secs`  | inferred budget window                 | Leave the day-ish default if only refill was measured — say so in provenance. |
| `bucket_scope` | stage 0 (`per_credential` / `broader…`)|                                               |
| `provenance`   | probe date + **per-axis confidence**   | Mark any deferred/warm axis explicitly.       |

Then supersede the guessed model (120s / day-ish) in
`docs/solutions/integration-issues/ls-gateway-igw00201-bulk-minute-ingest-drip-feed.md`
with the measured numbers + probe date. (It already has a provisional-tooling section to
overwrite.)

**Success = no axis silently absent:** scope, cold-budget, and refill are each either a
measured number or an explicitly-deferred-to-cold-window note.

## U7 — verify t1444, re-freeze top-40, run the acceptance ingest

### Step 1 — capture the top-40 (this *is* the t1444 live verify)

Reaching 40 requires page 2+, which only the header-pagination fix enables; U5's guard
turns a page-1 re-serve regression into a loud non-zero exit.

```bash
LS_CAPTURE_LANE_FILE=.env.domestic LS_CAPTURE_N=40 \
LS_CAPTURE_OUT=lab/config/turn4-universe.json \
  ./target/debug/capture-universe
```

- Exits **non-zero, writing nothing** if fewer than 40 come back → the t1444 fix's live
  leg failed; go back to SDK debugging, **not** more ingest attempts (a plan stop
  condition).
- A board that legitimately ends early: `LS_CAPTURE_ALLOW_SHORT=1` overrides and
  provenance records `requested_n`.

### Step 2 — drip ingest into a FRESH data home

The stale 20-symbol `data/turn4` is parked, not reused. The script pins the shared spend
ledger (`LS_SPEND_LEDGER_FILE=adapters/nautilus/state/spend-ledger.json`) so it survives
the fresh home.

```bash
LS_DATA_HOME=./data/turn4-fresh \
LS_TURN4_SDATE=<minute floor YYYYMMDD> LS_TURN4_EDATE=<range end YYYYMMDD> \
  bash adapters/nautilus/scripts/turn4-ingest.sh
```

### Step 3 — accept (R13)

```bash
LS_DATA_HOME=./data/turn4-fresh LS_STATUS_SDATE=<SD> LS_STATUS_EDATE=<ED> \
  ./target/debug/lab-research catalog status                       # must print GO

LS_DATA_HOME=./data/turn4-fresh LS_STATUS_SDATE=<SD> LS_STATUS_EDATE=<ED> \
  ./target/debug/lab-research catalog status | grep -c '1-MINUTE:' # must equal 40
```

**Done = GO status + `1-MINUTE:` count == 40 + zero manual re-runs after start.**

If `IGW00201` fires where the ledger predicted headroom, **stop and record the
model-miss** (the ledger's `model_misses` counter already tracks it) — that is data for
the model, not a retry loop.
