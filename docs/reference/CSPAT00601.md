## Errors & validation

**Reachable gateway errors** (explained once from the shared catalog; environment/entitlement codes are not reproduced per TR):

- `00000` — Success. The gateway processed the request and returned valid data.
- `904` — The market session required for this TR is closed. An environment condition, not a request defect: the same request succeeds inside the correct trading window. Retry in-session.
- `01900` — This service is not provided in the Paper (모의투자) environment (모의투자에서는 해당업무가 제공되지 않습니다). A per-service capability gate: no Paper account can clear it. Not a problem with your request. Retry against a Production credential set, or treat the TR as paper-incompatible.
- `01491` — This paper account cannot place orders (모의투자 주문이 불가한 계좌입니다). A per-account capability gate distinct from 01900: the request reached the gateway and was cleanly rejected, nothing was placed. Swap in an order-enabled paper account to clear it.
- `01407` — A business-level order rejection observed on CSPAT00601's `IsuNo`-omitted submit variant (§30 differential, 2026-07-13). The required symbol was omitted; the gateway answered on merits and placed nothing (a distinct reject, not a may-rest). The caller fixes it by supplying `IsuNo`.
- `IGW40011` — A request field the gateway expects as a JSON number was sent as a quoted string. Serialize numeric request fields as JSON numbers (`string_as_number` / `string_as_decimal`) rather than strings. This is a request-shape defect the caller can fix.
